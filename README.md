# Anita Tan - Technical Portfolio

A personal portfolio website showcasing my engineering projects, focusing on full-stack software development and artificial intelligence architecture. 

## Tech Stack

* Frontend: React
* Build Tool: Vite
* Styling: Custom CSS (Responsive)
* Hosting: GitHub Pages

## Local Development

To run this project locally:

1. Clone the repository:
   git clone https://github.com/anitatan2003/anitatan2003.github.io.git

2. Navigate into the directory:
   cd anitatan2003.github.io

3. Install dependencies:
   npm install

4. Start the local development server:
   npm run dev

## Deployment

This project uses the `gh-pages` package for deployment. The `main` branch holds the source code, and the `gh-pages` branch serves the compiled build.

To push updates to the live site:
1. Ensure you are on the `main` branch.
2. Commit and push your latest code changes to `main`.
3. Run the deployment script:
   npm run deploy
